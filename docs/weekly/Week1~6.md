## 2. 発生した問題と解決策
開発の最初の6週間で、様々な課題に直面しましたが、その都度学びながら対応してきました。以下に、各週で経験した一部の問題と、
その解決方法を簡単にまとめさせていただきます。

### 🧱 第1週：プロジェクト構造 & CI
- **問題**: IntelliJ が Java プロジェクトを認識せず、CI も `pom.xml` を見つけられない
- **解決策**: `pom.xml` と `src` をルート直下へ移動 → IntelliJ で Maven プロジェクト認識 → GitHub Actions 正常実行

---

### 💾 第2週：DB 接続エラー
- **問題**: Postman でジョブ保存/参照が失敗、DB 接続エラー発生
- **解決策**: `application.properties` で DB 接続情報を修正 + PostgreSQL JDBC 依存関係を追加 → 正常接続確認

---

### 📎 第3週：ノート関連問題
- **問題1**: Job ページでノートが表示されない → JobId が関連付けられていなかった
- **解決策**: API 送信時に正しい `jobId` を指定

- **問題2**: 添付ファイルが表示されない
- **解決策**: `uploadMulti` API のパラメータ形式を修正 → ダウンロードリンク表示成功

- **問題3**: ダウンロード不可
- **解決策**: `/api/notes/download/{filename}` に修正 → ファイル取得成功

---

### 🔐 第4週：ログイン認証失敗
- **問題**: Postman でログイン常に 401
- **解決策**:
    1. `UserController` コンストラクタを 1 つに統合
    2. DB 登録状況確認
    3. `UserService` のパスワード暗号化修正
    4. `JwtUtil` の SecretKey ロジック修正
    5. 再テストで `200 OK` + JWT トークン取得成功

---

### 🧱 第5週：Note 表示不具合
- **問題**: Note が表示されない or 重複表示
- **解決策**: DTO フィールド名誤記を修正 & Thymeleaf の `<table>` 重複処理を修正 → 正常表示

---

### 🧱 第6週：削除ボタン & 自動更新
- **問題1**: Note 削除ボタンが動作しない → `id` が null
- **解決策**: Service に `id` フィールド追加 → 正常削除

- **問題2**: アクセストークン期限切れ時に自動更新されず `/login` へリダイレクト
- **解決策**: `/auth/silent-refresh` エンドポイント追加 → Refresh Cookie で更新 → 有効期限切れ時の UX 改善
