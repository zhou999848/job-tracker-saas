## 2. 発生した問題と解決策(発生した問題と解決策を説明するビデオへのリンク:https://youtu.be/ra1dJAeK3H8)

- **問題①（Day 4）**  
  ノート削除ボタンが動作せず、Note ID がすべて `null` となっていた。
    - **原因**: `note.html` に ID が正しく渡っていなかった
    - **解決策**: `NoteService` の `viewNote` メソッドに ID フィールドを追加し、正常にデータを渡すよう修正

- **問題②（Day 7）**  
  アクセストークンの有効期限切れ後、`/jobs` ページへアクセスすると自動更新されず `/login` へ直接リダイレクトされた。
    - **原因**: `AuthenticationEntryPoint` がページルートに対して 302 リダイレクトを返し、`/api/auth/refresh` が呼ばれなかった
    - **解決策**: `/auth/silent-refresh` エンドポイントを追加し、REFRESH Cookie を用いて新しい ACCESS を発行 → 成功時は元のページへリダイレクト、失敗時は `/login` へリダイレクト
